Set MONGODB_URI in your backend hosting environment for durable data. Set JWT_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD, ADMIN_SECURITY_PIN and FRONTEND_URL securely. Never commit .env. Existing data.json is excluded because it can contain private user records; back up and migrate existing records before replacing a deployed database. Run npm install in backend and frontend folders.
